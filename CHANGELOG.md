# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-18

### Added
- Indonesian Legal Chatbot Assistant powered by LlamaIndex, Chroma vector store, and Groq/Ollama LLMs.
- Document ingestion pipeline processing Indonesian legal codes, statutes, and regulatory documents.
- Modular `src/` facade and multi-tier containerized microservice architecture.
- Multi-aspect CI validation including Ruff linting, test suite, and Trivy security scanning.
- Single-command Makefile runner for installation, testing, linting, and running.
- Non-root user hardened Dockerfile for secure production container deployment.
- Formal open source governance, semantic versioning, and Dependabot vulnerability updates.
